باني الواجهات المتقدم (Advanced UI Mockup Builder)

أداة متطورة تعمل بالكامل داخل المتصفح — بدون تثبيت، بدون خادم، وبدون اتصال بالإنترنت — لبناء نماذج أولية سريعة لواجهات التطبيقات والمواقع، مع ميزات متقدمة لإدارة الطبقات، إضافة ملاحظات لكل عنصر، حفظ تلقائي، وتصدير متعدد الصيغ (HTML، CSS، JSON، ونص وصفي) لإرسالها لوكيل ذكاء اصطناعي (مثل Claude) ليحوّلها إلى واجهة حقيقية بدقة عالية.

مبنية كملف HTML واحد فقط (Vanilla JS، بدون أي مكتبات خارجية)، لذلك تعمل مباشرة على الهاتف والكمبيوتر بمجرد فتحها في أي متصفح.

---

لماذا هذه الأداة؟

عند وصف تصميم واجهة بالكلام فقط لوكيل ذكاء اصطناعي، يصعب إيصال الفكرة بدقة (الألوان، المواقع، الأحجام، شكل الأزرار...). هذه الأداة تتيح لك:

1. بناء نموذج متكامل للواجهة بالسحب والإفلات.
2. إضافة ملاحظات وشرح لكل عنصر لتوضيح الغرض منه أو وظيفته.
3. ترتيب الطبقات بدقة (سحب وإفلات، رفع/خفض) للتحكم بترتيب العناصر فوق بعضها.
4. تصديره كصورة PNG، أو HTML كامل، أو CSS، أو وصف نصي/JSON دقيق.
5. إرسال المخرجات للوكيل ليطبّقها فورًا دون حاجة لتخمين.

---

المزايا الجديدة (آخر إصدار)

🧩 إدارة متقدمة للطبقات (Layers)

· سحب وإفلات العناصر في قائمة الطبقات لإعادة ترتيبها (يدعم اللمس والفأرة).
· أزرار رفع/خفض في تبويب التنسيق لنقل العنصر المحدد خطوة لأعلى أو لأسفل.
· عرض رقم الطبقة (Z-Index) بجانب كل عنصر في القائمة.
· تحديث فوري للترتيب على الشاشة.

💾 حفظ تلقائي واستعادة

· يحفظ التصميم تلقائيًا في localStorage بعد أي تغيير.
· عند فتح الصفحة مجددًا، يُستعاد آخر تصميم تلقائيًا.
· يمكن تصدير التصميم كملف JSON وحفظه على الجهاز، واستيراده لاحقًا.

🔍 تكبير/تصغير (Zoom)

· استخدام عجلة الفأرة مع الضغط على Ctrl لتكبير/تصغير منطقة العرض.
· زر 🔍 في الأعلى للتبديل بين مستويات التكبير (100%، 120%، 80%).

📝 شرح وملاحظات لكل عنصر

· حقل "📝 شرح/ملاحظة" في تبويب التنسيق، يمكنك كتابة أي شرح للعنصر المحدد.
· تظهر أيقونة ✏️ على العنصر نفسه في منطقة التصميم للإشارة إلى وجود ملاحظة.
· في قائمة الطبقات، يظهر رمز ✏️ بجانب اسم العنصر الذي يحتوي على ملاحظة.
· تُضمن الملاحظات في جميع مخرجات التصدير (نص، JSON، HTML، CSS).

📄 تحكم متقدم بالنص

· نص متعدد الأسطر (textarea) بدلاً من حقل نصي عادي، لدعم الفقرات.
· محاذاة عمودية للنص (أعلى، وسط، أسفل) بالإضافة إلى المحاذاة الأفقية.
· إمكانية تغيير نوع الخط (اختيار من قائمة خطوط شائعة).

🌐 تصدير متعدد الصيغ

· تنزيل صورة PNG (بدقة عالية).
· نسخ وصف نصي تفصيلي مع تضمين الملاحظات.
· نسخ بيانات JSON مع حقل note.
· تصدير HTML كامل يعيد إنتاج التصميم (مع تعليقات الملاحظات).
· تصدير CSS للأنماط فقط (مع تعليقات الملاحظات).
· استيراد/تصدير التصميم كملف JSON للحفظ والمشاركة.

📊 شريط حالة (Status Bar)

· يعرض عدد العناصر الموجودة.
· يعرض معلومات العنصر المحدد (نوعه وإحداثياته).

عناصر التصميم

· زر (Button)
· مربع / مستطيل (Rect)
· دائرة (Circle)
· نص (Text)
· شريط قائمة (Menu bar)
· حقل إدخال (Input field)
· بطاقة (Card)
· خط فاصل (Divider)
· صورة نائبة (Image placeholder)

---

التحكم والتحرير

· سحب العناصر لتحريكها، ومقبض في الزاوية لتغيير الحجم.
· خطوط محاذاة تلقائية (Snapping) تظهر عند محاذاة العنصر مع مركز الشاشة أو حواف عناصر أخرى.
· تحريك دقيق بالأسهم على لوحة المفاتيح (Shift + سهم = خطوة أكبر).
· حذف بمفتاح Delete، وتكرار بـ Ctrl/Cmd + D.
· تراجع / إعادة كامل (Ctrl/Cmd + Z و Ctrl/Cmd + Shift + Z)، أو من الأزرار أعلى الصفحة.

التنسيق

· لون التعبئة ولون النص (لوحة ألوان جاهزة + منتقي ألوان حر).
· استدارة الحواف، حجم الخط، سماكة الإطار، الشفافية.
· محاذاة النص (أفقية: يمين/وسط/يسار، عمودية: أعلى/وسط/أسفل).
· اختيار نوع الخط (Tahoma، Arial، Times New Roman، Courier New، Segoe UI).
· مفتاح "مظهر لامع (مائي)" لإعطاء الأزرار والعناصر تأثير زجاجي/لامع بضغطة واحدة.
· تبويب طبقات لعرض كل العناصر وحذفها أو تحديدها وسحبها لإعادة الترتيب.
· لون خلفية كامل للشاشة.
· وضعان جاهزان لحجم الشاشة: هاتف / شاشة كبيرة، مع إمكانية تكبير/تصغير العرض.

التصدير (أهم ميزة لإرسالها للوكيل)

· تنزيل التصميم كصورة PNG مباشرة من داخل الأداة.
· نسخ وصف نصي مفصّل لكل عنصر (نوعه، موقعه، حجمه، ألوانه، وملاحظاته) جاهز للصقه في محادثة الوكيل.
· نسخ بيانات JSON منظّمة مع حقل note لكل عنصر.
· تنزيل صفحة HTML كاملة تعيد إنتاج التصميم.
· تنزيل ملف CSS للأنماط فقط.
· حفظ التصميم كملف JSON لاستيراده لاحقًا (يحتفظ بجميع البيانات بما فيها الملاحظات).
· استيراد تصميم من ملف JSON سابق.

---

طريقة الاستخدام

1. افتح ملف mockup-builder-v2.html في أي متصفح (على الهاتف أو الكمبيوتر) — بالنقر المزدوج عليه، أو برفعه على استضافة ثابتة وفتح الرابط.
2. من تبويب "إضافة"، اختر العنصر الذي تريده لإضافته إلى الشاشة.
3. اسحب العنصر لتحريكه، واسحب النقطة الصغيرة في زاويته لتغيير حجمه.
4. من تبويب "تنسيق"، عدّل اللون والنص والاستدارة والشفافية وغيرها.
   · يمكنك إضافة ملاحظة/شرح لكل عنصر في حقل "📝 شرح/ملاحظة".
5. من تبويب "الطبقات"، يمكنك:
   · رؤية جميع العناصر مرتبة (الأعلى في الأعلى).
   · سحب أي عنصر لأعلى أو لأسفل لإعادة ترتيبه.
   · النقر على عنصر لتحديده في الشاشة.
   · حذف عنصر بالضغط على ×.
6. من تبويب "خلفية"، غيّر لون خلفية الشاشة.
7. من تبويب "تصدير"، اختر الصيغة المناسبة (PNG، وصف نصي، JSON، HTML، CSS، أو حفظ/استيراد ملف التصميم).
8. أرسل الصورة + الوصف النصي (أو JSON) معًا لوكيل الذكاء الاصطناعي واطلب منه بناء نفس الواجهة.

التقنية

· ملف HTML واحد فقط، بلغة JavaScript خالصة (بدون React أو أي إطار عمل).
· لا توجد اعتماديات خارجية (لا CDN، لا مكتبات) — يعمل حتى بدون إنترنت بعد تحميله.
· التصميم متجاوب: يعمل على المتصفح المكتبي ومتصفح الهاتف على حد سواء.
· تصدير الصورة يتم بالكامل داخل المتصفح عبر Canvas API، دون رفع أي بيانات لأي خادم.
· يستخدم localStorage للحفظ التلقائي، مع إمكانية تصدير/استيراد الملفات يدويًا.
· دعم HTML5 Drag & Drop و Pointer Events للتعامل مع اللمس والفأرة معًا.
