# باني الواجهات المبسط (Simple UI Mockup Builder)

أداة صغيرة تعمل بالكامل داخل المتصفح — بدون تثبيت، بدون خادم، وبدون اتصال بالإنترنت — لبناء نماذج أولية سريعة لواجهات التطبيقات والمواقع، ثم تصديرها (كصورة أو كوصف نصي/JSON) لإرسالها لوكيل ذكاء اصطناعي (مثل Claude) ليحوّلها إلى واجهة حقيقية بسرعة ودقة أكبر.

مبنية كملف `HTML` واحد فقط (Vanilla JS، بدون أي مكتبات خارجية)، لذلك تعمل مباشرة على الهاتف والكمبيوتر بمجرد فتحها في أي متصفح.

---

## لماذا هذه الأداة؟

عند وصف تصميم واجهة بالكلام فقط لوكيل ذكاء اصطناعي، يصعب إيصال الفكرة بدقة (الألوان، المواقع، الأحجام، شكل الأزرار...). هذه الأداة تتيح لك:

1. بناء نموذج مبسط للواجهة بالسحب والإفلات.
2. تصديره كصورة PNG أو كوصف نصي/JSON دقيق.
3. إرساله للوكيل ليطبّقه فورًا بدل تخمين ما تقصده.

---

## المزايا

### عناصر التصميم
- زر (Button)
- مربع / مستطيل (Rect)
- دائرة (Circle)
- نص (Text)
- شريط قائمة (Menu bar)
- حقل إدخال (Input field)
- بطاقة (Card)
- خط فاصل (Divider)
- صورة نائبة (Image placeholder)

### التحكم والتحرير
- سحب العناصر لتحريكها، ومقبض في الزاوية لتغيير الحجم.
- **خطوط محاذاة تلقائية (Snapping)** تظهر عند محاذاة العنصر مع مركز الشاشة أو حواف عناصر أخرى.
- تحريك دقيق بالأسهم على لوحة المفاتيح (`Shift` + سهم = خطوة أكبر).
- حذف بمفتاح `Delete`، وتكرار بـ `Ctrl/Cmd + D`.
- **تراجع / إعادة** كامل (`Ctrl/Cmd + Z` و `Ctrl/Cmd + Shift + Z`)، أو من الأزرار أعلى الصفحة.

### التنسيق
- لون التعبئة ولون النص (لوحة ألوان جاهزة + منتقي ألوان حر).
- استدارة الحواف، حجم الخط، سماكة الإطار، الشفافية.
- محاذاة النص (يمين / وسط / يسار).
- مفتاح **"مظهر لامع (مائي)"** لإعطاء الأزرار والعناصر تأثير زجاجي/لامع بضغطة واحدة.
- تبويب طبقات لعرض كل العناصر وحذفها أو تحديدها بسرعة.
- لون خلفية كامل للشاشة.
- وضعان جاهزان لحجم الشاشة: هاتف / شاشة كبيرة.

### التصدير (أهم ميزة لإرسالها للوكيل)
- **تنزيل التصميم كصورة PNG** مباشرة من داخل الأداة (بدون الحاجة لالتقاط لقطة شاشة يدويًا).
- **نسخ وصف نصي مفصّل** لكل عنصر (نوعه، موقعه، حجمه، ألوانه...) جاهز للصقه في محادثة الوكيل.
- **نسخ بيانات JSON منظّمة** لمن يريد دقة أعلى أو دمجها في أدوات أخرى.

## طريقة الاستخدام

1. افتح ملف `mockup-builder.html` في أي متصفح (على الهاتف أو الكمبيوتر) — بالنقر المزدوج عليه، أو برفعه على استضافة ثابتة (GitHub Pages مثلًا) وفتح الرابط.
2. من تبويب **"إضافة عناصر"**، اختر العنصر الذي تريده لإضافته إلى الشاشة.
3. اسحب العنصر لتحريكه، واسحب النقطة الصغيرة في زاويته لتغيير حجمه.
4. من تبويب **"تنسيق العنصر"**، عدّل اللون والنص والاستدارة والشفافية وغيرها.
5. كرّر حتى تكتمل الواجهة كما تتخيلها.
6. من تبويب **"تصدير للوكيل"**، نزّل الصورة أو انسخ الوصف النصي/JSON.
7. أرسل الصورة + الوصف النصي معًا لوكيل الذكاء الاصطناعي واطلب منه بناء نفس الواجهة.

## اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|---|---|
| `Delete` / `Backspace` | حذف العنصر المحدد |
| الأسهم | تحريك العنصر المحدد (خطوة صغيرة) |
| `Shift` + الأسهم | تحريك العنصر المحدد (خطوة أكبر) |
| `Ctrl/Cmd + D` | تكرار العنصر المحدد |
| `Ctrl/Cmd + Z` | تراجع |
| `Ctrl/Cmd + Shift + Z` | إعادة |

## التقنية

- ملف `HTML` واحد فقط، بلغة JavaScript خالصة (بدون React أو أي إطار عمل).
- لا توجد اعتماديات خارجية (لا CDN، لا مكتبات) — يعمل حتى بدون إنترنت بعد تحميله.
- التصميم متجاوب: يعمل على المتصفح المكتبي ومتصفح الهاتف على حد سواء.
- تصدير الصورة يتم بالكامل داخل المتصفح عبر `Canvas API`، دون رفع أي بيانات لأي خادم.

> ملاحظة: لا تستخدم الأداة أي تخزين محلي (localStorage) — كل تصميم يعيش أثناء الجلسة فقط، لذا احرص على التصدير (صورة أو JSON) قبل إغلاق الصفحة إن أردت الاحتفاظ بالتصميم.
