# باني الواجهات المتقدم (Advanced UI Mockup Builder)

أداة متطورة تعمل بالكامل داخل المتصفح — بدون تثبيت، بدون خادم، وبدون اتصال بالإنترنت — لبناء نماذج أولية سريعة لواجهات التطبيقات والمواقع، ثم تصديرها (كصورة، HTML، CSS، أو وصف نصي/JSON) لإرسالها لوكيل ذكاء اصطناعي (مثل Claude) ليحوّلها إلى واجهة حقيقية بدقة عالية.

مبنية كملف `HTML` واحد فقط (Vanilla JS، بدون أي مكتبات خارجية)، لذلك تعمل مباشرة على الهاتف والكمبيوتر بمجرد فتحها في أي متصفح.

---

## لماذا هذه الأداة؟

عند وصف تصميم واجهة بالكلام فقط لوكيل ذكاء اصطناعي، يصعب إيصال الفكرة بدقة (الألوان، المواقع، الأحجام، شكل الأزرار...). هذه الأداة تتيح لك:

1. بناء نموذج متكامل للواجهة بالسحب والإفلات.
2. إضافة ملاحظة توضيحية لكل عنصر لشرح الغرض منه أو وظيفته.
3. ترتيب الطبقات بدقة (سحب وإفلات، رفع/خفض).
4. تصديره كصورة PNG، أو HTML كامل، أو CSS، أو وصف نصي/JSON دقيق.
5. إرسال المخرجات للوكيل ليطبّقها فورًا بدل تخمين ما تقصده.

## المزايا

### عناصر التصميم
- زر (Button)
- مربع / مستطيل (Rect)
- دائرة (Circle)
- نص (Text)
- شريط قائمة (Menu bar)
- حقل إدخال (Input field)
- بطاقة (Card)
- خط فاصل (Divider)
- صورة نائبة (Image placeholder)

### التحكم والتحرير
- سحب العناصر لتحريكها، ومقبض في الزاوية لتغيير الحجم.
- **خطوط محاذاة تلقائية (Snapping)** تظهر عند محاذاة العنصر مع مركز الشاشة أو حواف عناصر أخرى.
- تحريك دقيق بالأسهم على لوحة المفاتيح (`Shift` + سهم = خطوة أكبر).
- حذف بمفتاح `Delete`، وتكرار بـ `Ctrl/Cmd + D`.
- **تراجع / إعادة** كامل (`Ctrl/Cmd + Z` و `Ctrl/Cmd + Shift + Z`)، أو من الأزرار أعلى الصفحة.
- **تكبير / تصغير** لمنطقة العرض عبر `Ctrl` + عجلة الفأرة، أو زر 🔍 أعلى الصفحة (100% / 120% / 80%).

### إدارة الطبقات
- تبويب طبقات يعرض كل العناصر مرتبة (الأعلى في الأعلى) مع رقم ترتيبها (Z-Index).
- سحب وإفلات أي عنصر في القائمة لإعادة ترتيبه (يدعم اللمس والفأرة).
- أزرار رفع/خفض في تبويب التنسيق لنقل العنصر المحدد خطوة واحدة.
- تحديد أو حذف أي عنصر مباشرة من القائمة.

### ملاحظات على العناصر
- حقل "📝 شرح/ملاحظة" في تبويب التنسيق لكتابة أي توضيح على العنصر المحدد.
- تظهر أيقونة ✏️ على العنصر في منطقة التصميم، وبجانبه في قائمة الطبقات، للإشارة إلى وجود ملاحظة.
- تُضمَّن الملاحظات تلقائيًا في جميع صيغ التصدير (نص، JSON، HTML، CSS) لتصل للوكيل كاملة.

### التنسيق
- لون التعبئة ولون النص (لوحة ألوان جاهزة + منتقي ألوان حر).
- استدارة الحواف، حجم الخط، سماكة الإطار، الشفافية.
- محاذاة النص: أفقية (يمين / وسط / يسار) وعمودية (أعلى / وسط / أسفل).
- اختيار نوع الخط (Tahoma، Arial، Times New Roman، Courier New، Segoe UI).
- نص متعدد الأسطر (Textarea) لدعم الفقرات الطويلة.
- مفتاح **"مظهر لامع (مائي)"** لإعطاء الأزرار والعناصر تأثير زجاجي بضغطة واحدة.
- لون خلفية كامل للشاشة.
- وضعان جاهزان لحجم الشاشة: هاتف / شاشة كبيرة.

### الحفظ والاستعادة
- **حفظ تلقائي** في `localStorage` بعد أي تغيير — يُستعاد آخر تصميم تلقائيًا عند فتح الصفحة من جديد.
- تصدير التصميم كملف JSON وحفظه على الجهاز، واستيراده لاحقًا لمتابعة العمل عليه أو مشاركته.

### شريط الحالة
- يعرض عدد العناصر الموجودة في التصميم.
- يعرض نوع وإحداثيات العنصر المحدد حاليًا.

### التصدير (أهم ميزة لإرسالها للوكيل)
- **تنزيل التصميم كصورة PNG** بدقة عالية، مباشرة من داخل الأداة.
- **نسخ وصف نصي مفصّل** لكل عنصر (نوعه، موقعه، حجمه، ألوانه، وملاحظاته) جاهز للصقه في محادثة الوكيل.
- **نسخ بيانات JSON منظّمة** مع حقل ملاحظة (`note`) لكل عنصر.
- **تنزيل صفحة HTML كاملة** تعيد إنتاج التصميم مباشرة، مع تعليقات الملاحظات داخل الكود.
- **تنزيل ملف CSS** للأنماط فقط، مع تعليقات الملاحظات.
- **حفظ/استيراد التصميم كملف JSON** كامل البيانات بما فيها الملاحظات، لإعادة فتحه أو مشاركته لاحقًا.

## طريقة الاستخدام

1. افتح ملف `mockup-builder-v2.html` في أي متصفح (على الهاتف أو الكمبيوتر) — بالنقر المزدوج عليه، أو برفعه على استضافة ثابتة (GitHub Pages مثلًا) وفتح الرابط.
2. من تبويب **"إضافة"**، اختر العنصر الذي تريده لإضافته إلى الشاشة.
3. اسحب العنصر لتحريكه، واسحب النقطة الصغيرة في زاويته لتغيير حجمه.
4. من تبويب **"تنسيق"**، عدّل اللون والنص والاستدارة والشفافية وغيرها، وأضف ملاحظة توضيحية إن أردت.
5. من تبويب **"الطبقات"**، رتّب العناصر بالسحب، أو حدّدها، أو احذفها.
6. من تبويب **"خلفية"**، غيّر لون خلفية الشاشة.
7. من تبويب **"تصدير"**، اختر الصيغة المناسبة: صورة PNG، وصف نصي، JSON، HTML، CSS، أو احفظ/استورد ملف التصميم.
8. أرسل الصورة + الوصف النصي (أو JSON) معًا لوكيل الذكاء الاصطناعي واطلب منه بناء نفس الواجهة.

## اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|---|---|
| `Delete` / `Backspace` | حذف العنصر المحدد |
| الأسهم | تحريك العنصر المحدد (خطوة صغيرة) |
| `Shift` + الأسهم | تحريك العنصر المحدد (خطوة أكبر) |
| `Ctrl/Cmd + D` | تكرار العنصر المحدد |
| `Ctrl/Cmd + Z` | تراجع |
| `Ctrl/Cmd + Shift + Z` | إعادة |
| `Ctrl` + عجلة الفأرة | تكبير/تصغير منطقة العرض |

## التقنية

- ملف `HTML` واحد فقط، بلغة JavaScript خالصة (بدون React أو أي إطار عمل).
- لا توجد اعتماديات خارجية (لا CDN، لا مكتبات) — يعمل حتى بدون إنترنت بعد تحميله.
- التصميم متجاوب: يعمل على المتصفح المكتبي ومتصفح الهاتف على حد سواء.
- تصدير الصورة يتم بالكامل داخل المتصفح عبر `Canvas API`، دون رفع أي بيانات لأي خادم.
- يستخدم `localStorage` للحفظ التلقائي، مع إمكانية تصدير/استيراد ملف JSON يدويًا.
- يدعم `Pointer Events` للتعامل مع اللمس والفأرة معًا في السحب وإعادة ترتيب الطبقات.
